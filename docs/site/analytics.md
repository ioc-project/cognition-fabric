# Analytics

[SCOPE](https://ioc-project.github.io/scope/) ingests and analyzes MAS
telemetry. CEs can read the resulting evidence directly through the
[SCOPE Analytics APIs](https://ioc-project.github.io/scope/platform/api/).

In the current stack, SCOPE also serves the separate Cognition Store API. CEs
use it to submit new findings and retrieve previous findings.
