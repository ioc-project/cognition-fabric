## Focus Areas

| Area                          | Description                                                                                                                                                                                                                 |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **OXP core integration**      | Refactor CF to integrate OXP as a first-class source of cognitive signal — trajectories, enriched traces, and CE-produced findings flow into and through the fabric via OXP.                                                |
| **Cognition Store**           | Build and maintain the store as required by COGS and GATS CEs: a structured, queryable surface for CE findings, cognitive context, and interaction history.                                                                 |
| **Three-tier CF API surface** | Analytics APIs (read-only observability), Active APIs (direct MAS engagement), and Enforcing APIs (block / modify / inject via the Enforcement Proxy T3). CF defines the contracts; the Proxy executes enforcement in-path. |
| **CE support**                | Routing and chaining of Cognition Engines across the fabric — enabling CEs (including OXP CEs) to be composed, sequenced, and triggered by the fabric.                                                                      |
| **L9 interaction with MAS**   | Passive (Analytics), active (Active APIs), and enforcing (Enforcing APIs) modes of L9 interaction, surfaced as the Get/Enforce CF APIs.                                                                                     |
