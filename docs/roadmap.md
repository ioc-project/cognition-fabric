## Focus Areas

| Area                          | Description                                                                                                                                                                                                                 |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **OXP core integration**      | Refactor CF to integrate OXP as a first-class source of cognitive signal — trajectories, enriched traces, and CE-produced findings flow into and through the fabric via OXP.                                                |
| **Two-tier CF API surface**   | Active APIs (direct MAS engagement) and Enforcing APIs (block / modify / inject via the Enforcement Proxy T3). Analytics APIs and the Cognition Store are owned by OXP. CF defines the contracts; the Proxy executes enforcement in-path. |
| **CE support**                | Routing and chaining of Cognition Engines across the fabric — enabling CEs (including OXP CEs) to be composed, sequenced, and triggered by the fabric.                                                                      |
| **L9 interaction with MAS**   | Active (Active APIs) and enforcing (Enforcing APIs) modes of L9 interaction, surfaced as the Get/Enforce CF APIs.                                                                                     |
